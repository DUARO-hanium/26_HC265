# Z-axis Lift Actuator

이 폴더는 OMX-AI 로봇팔에 결합되는 Z축 이동 장치 파일을 정리한 공간입니다.

## 파일
```
- stp_file        # stl 파일에 대한 step 파일
- z-axis.stl      # Z축 리프트 액추에이터
```

## 설계 방향

- 리드스크류(lead screw) 방식을 활용하여 정밀한 상하 이동이 가능하면서도 소형이고 견고한 구조로 설계
- 로봇팔이 의류 양끝단을 파지한 상태로 Z축을 상승시키면 의류가 중력에 의해 자연스럽게 펼쳐지며 주름이 해소되도록 하여, 단일 카메라로도 의류 전체를 촬영·검수할 수 있는 환경을 만드는 것을 목표로 함
- 이 STL 파일들은 3D 모델 공유와 출력 검토를 위한 파일입니다.
