# DUARO 검수 대시보드

프로젝트 폴더에서 Python 환경을 활성화한 뒤 `streamlit run app.py`를 실행합니다.

## 영상 기반 검수 흐름

1. 앱을 열면 1번 카메라 영상이 자동 재생됩니다.
2. 영상의 바운딩박스가 처음 나타나는 약 89초부터 작업 상태와 현재 결과가 `검수 진행 중`으로 바뀝니다.
3. 1번 영상이 끝나면 `추가 확인 필요`로 바뀝니다.
4. 사용자가 `2번 카메라`를 선택하면 2번 영상이 자동 재생됩니다.
5. 2번 영상이 끝나면 진행 단계가 `결과 저장`으로 바뀌고, 검수 완료와 확정 불량이 각각 1건으로 집계됩니다.

상태 전환은 서버에서 계산한 영상 재생 시간 기준입니다. 브라우저에서 영상을 일시정지하거나 재생 위치를 옮기면 화면의 상태 전환 시점과 영상이 어긋날 수 있습니다. 다시 확인하려면 `처음부터 다시 보기`를 누릅니다.

## 저장된 검수 영상

- `videos/camera_1.mp4`: 1번 카메라, 162.208초
- `videos/camera_2.mp4`: 2번 카메라, 180.467초

선택한 카메라의 MP4를 자동 재생하며 반복하지 않습니다. 영상 파일이 없으면 파일을 추가하라는 메시지를 표시합니다. 대용량 영상은 `.gitignore`에서 제외했습니다. 브라우저 호환성을 위해 MP4 컨테이너와 H.264 비디오 코덱을 권장합니다.

영상 경로와 길이, 바운딩박스 시작 시점은 `app.py` 상단의 `VIDEOS`, `DURATIONS`, `BBOX_AT`에서 변경할 수 있습니다.

## 연결 상태 표시

현재 UI는 로봇, 카메라, AI를 모두 `연결됨`으로 표시하도록 구성했습니다. 이 표시는 화면 시연용 상태이며 실제 장비의 연결 신호를 읽는 기능은 아직 연결하지 않았습니다.
