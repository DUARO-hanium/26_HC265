# Source Code

DUARO의 실행 소스코드를 기능별로 정리하는 디렉터리입니다.

- `process_controller/` : 전체 공정 상태 및 작업 순서 제어
- `perception/` : 패키지·의류 인식, 파지점 추정, 오염 검사, 좌표 변환
- `manipulation/` : 듀얼암 이동, 파지, 재파지, Motion Planning, Record/Replay
- `hardware_control/` : Z-axis, Turntable, Gripper, OpenRB 제어
- `monitoring/` : 공정 상태 및 검사 결과 모니터링
